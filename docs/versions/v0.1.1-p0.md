# PeerAssist `0.1.1-p0` 版本说明

发布日期：2026-07-26

## 目标

修复教师首次使用时“管理员已经配置模型，但普通老师仍看到模型未配置”和平台任务存在后无法添加人工批注的问题，并清理注册回跳与任务终态摘要中的误导状态。

## 变更

- 普通老师可读取模型供应商、模型名、启用状态和凭据是否存在；Base URL、Key hint、revision、策略和配置标识仍只对管理员开放。
- 模型列表发现和模型配置写入继续限制为组织管理员操作。
- 登录后的工作台通过安全读取接口判断模型是否可用，不再调用管理员专用的模型发现接口。
- 平台审稿任务存在时，老师仍可把选区和人工意见加入证据队列；没有后端命令支持的“再次选区智能审稿”没有被伪解禁。
- 失败、取消、中断、阻断、等待确认和已完成任务不再统一显示“摘要正在生成”。
- 新用户注册完成后默认返回论文工作台 `/paper`，不再进入管理员页。

## 外部辅助

Claude CLI 以限定文件范围参与只读审阅，并在授权后修改 `model_settings.py` 与 `auth.py`。Codex 逐行检查其 diff，并用本地测试、Ruff、前端构建、镜像构建和运行态探针独立验证。侧边栏 Gemini 因当前会话没有浏览器控制接口而未调用，不将其计入本版本依据。
